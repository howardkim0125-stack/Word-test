# 영단어 단어장 (PWA)

아이패드에서 홈 화면에 추가해 앱처럼 쓰는 영단어 단어장 + 무작위 테스트 웹앱입니다.
HTML/CSS/JS만 사용하고, 데이터는 기기의 `localStorage`에 저장되며 오프라인에서도 동작합니다.

## 기능

- **단어 등록**: 영단어 / 뜻(쉼표로 여러 개) / 메모·예문, `word - 뜻` 형식 일괄 등록, 중복 단어 경고 후 덮어쓰기 선택
- **단어 목록**: 검색, 정렬, 수정, 삭제, 출제·오답 횟수와 정답률, 🔊 발음 듣기(en-US)
- **테스트**: 무작위 N개 출제(기본 20), 영→한 / 한→영 / 섞기, 주관식 / 객관식 4지선다, 완전 무작위 / 오답률 우선
  - 주관식은 Enter로 제출하고, 채점 결과가 나온 뒤 Enter를 한 번 더 누르면 다음 문제로 넘어갑니다. "정답 인정" 버튼으로 채점을 직접 고칠 수 있습니다.
  - 객관식은 외장 키보드의 숫자키 1~4로도 고를 수 있습니다.
- **결과**: 점수, 틀린 단어(내 답 vs 정답), 틀린 것만 다시 풀기, 단어별 통계 반영
- **백업**: JSON 내보내기·가져오기(합치기 / 전체 교체). 마지막 백업 후 7일이 지나면 알림이 뜹니다.
- **예시 단어 30개** 넣기·지우기 (설정 탭)

## 파일 구조

```
index.html          화면 구성
manifest.json       PWA 설정 (앱 이름, 아이콘, 전체 화면 표시)
sw.js               서비스 워커 (오프라인 캐시)
css/style.css       스타일 (가로·세로 화면, 다크 모드)
js/storage.js       localStorage 저장/불러오기
js/ui.js            토스트, 대화상자 등 공용 UI
js/speech.js        발음 듣기 (Web Speech API)
js/samples.js       예시 단어 30개
js/words.js         단어 등록 / 일괄 등록 / 중복 처리
js/list.js          단어 목록 / 검색 / 수정 / 삭제
js/quiz.js          테스트 출제 / 채점 / 결과
js/backup.js        JSON 백업 / 7일 백업 알림
js/app.js           앱 시작, 탭 전환, 설정 화면
icons/              앱 아이콘
```

## GitHub Pages에 올리기

1. **파일을 `main` 브랜치에 올립니다.**
   이 저장소(`word-test`)의 `main` 브랜치 맨 위에 `index.html`이 있어야 합니다.
2. GitHub에서 저장소 페이지를 열고 **Settings**(설정) 탭을 누릅니다.
3. 왼쪽 메뉴에서 **Pages**를 누릅니다.
4. **Build and deployment** 아래 **Source**를 **Deploy from a branch**로 고릅니다.
5. **Branch**는 `main`, 폴더는 `/ (root)`로 고르고 **Save**를 누릅니다.
6. 1~2분 기다린 뒤 Pages 화면을 새로 고치면 맨 위에
   `Your site is live at https://<아이디>.github.io/word-test/` 주소가 나타납니다.
   (저장소 **Actions** 탭에서 배포 진행 상황을 볼 수 있습니다.)
   - 무료 계정이면 GitHub Pages를 쓰려면 저장소가 **Public**(공개)이어야 합니다. 단어 데이터는 기기에만 저장되므로 저장소에 올라가지 않습니다.

### 아이패드 홈 화면에 추가하기

1. 아이패드 **Safari**로 위 주소를 엽니다. (홈 화면 추가는 Safari에서 하는 것이 가장 확실합니다.)
2. 주소창 옆 **공유 버튼(□↑)**을 누릅니다.
3. **홈 화면에 추가**를 누르고 → **추가**를 누릅니다.
4. 홈 화면의 "단어장" 아이콘으로 실행하면 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 없어도 동작합니다.

### 수정한 뒤 다시 배포하기

1. 파일을 고쳐서 `main`에 올립니다.
2. **`sw.js`의 `CACHE_VERSION`을 올려 주세요** (예: `'v1'` → `'v2'`).
   이 값을 바꾸지 않으면 아이패드가 예전에 캐시해 둔 파일을 계속 씁니다.
3. 앱을 한 번 열면 새 버전을 받아 두고, 앱을 완전히 닫았다가 다시 열면 적용됩니다.

## 주의 사항 (데이터)

- 데이터는 **그 기기, 그 브라우저 안에만** 저장됩니다. 홈 화면 앱과 Safari 탭은 저장 공간이 서로 따로입니다. 처음부터 홈 화면 앱으로 쓰세요.
- 홈 화면 앱을 삭제하면 데이터도 함께 지워집니다. **설정 → JSON 내보내기**로 주기적으로 백업하세요. 아이패드에서는 공유 시트가 열리며 **"파일에 저장"**으로 iCloud Drive 등에 저장할 수 있습니다.
- 다른 기기로 옮길 때는 백업 파일을 **설정 → JSON 가져오기**로 불러오세요.

## 내 컴퓨터에서 실행해 보기

서비스 워커는 `file://`에서 동작하지 않으므로 간단한 서버로 엽니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
