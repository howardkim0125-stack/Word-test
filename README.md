# 영단어 단어장 (PWA)

아이패드·휴대폰에서 홈 화면에 추가해 앱처럼 쓰는 영단어 단어장 + 무작위 테스트 웹앱입니다.
HTML/CSS/JS만 사용하고, 데이터는 기기의 `localStorage`에 저장되며 오프라인에서도 동작합니다.

## 기능

### 단어 등록
- **사전 10,474단어(숙어 640개 포함)**: 초등 기초 단어부터 수능 고난도 어휘·숙어까지. 단어마다 **난이도(초등 1 ~ 고등 3, 9단계)**와 **품사별 뜻**이 있습니다(예: bear — 명 곰 · 동 견디다, 참다, 낳다).
- **자동완성**: 영단어를 치면 접두사가 맞는 후보를 최대 6개 "단어 + 난이도 + 품사별 뜻"으로 보여 줍니다. 누르면 뜻이 칩으로 채워지고(품사마다 2개씩, 최대 5개) **Enter 한 번**으로 등록됩니다.
- **한글로 찾기**: 영단어 칸에 `포기하다`처럼 한글 뜻을 치면 abandon, give up 같은 영단어 후보가 나옵니다. 고르면 찾은 뜻이 첫 칩이 됩니다.
- **변화형 → 원형**: abandoned, studies, running, went처럼 입력해도 원형(abandon, study, run, go)을 찾아 줍니다.
  left·saw·found처럼 그 자체로도 단어인 경우는 "왼쪽의 / leave의 과거·과거분사"처럼 둘 다 보여 줍니다.
- **뜻 칩**: 칩을 누르면 빠지고, Enter나 쉼표로 직접 추가합니다. 직접 고친 뜻이 사전 뜻보다 항상 우선입니다.
- **중복 표시**: 입력 중에 "이미 있음 · (라이브러리 이름)"을 보여 줍니다.
- **사전에 없는 단어**: 영영 뜻(Free Dictionary), 참고용 번역(MyMemory), 네이버 사전 링크를 보여 줍니다. 인터넷이 없으면 조용히 직접 입력으로 넘어갑니다.
- **일괄 등록**: `word - 뜻` 형식, **영단어만** 적은 줄은 사전에서 뜻을 채웁니다. 사전에 없는 줄은 입력칸에 남겨 알려 줍니다.
- **방금 등록한 단어** 최근 10개와 항목별 **되돌리기**
- 저장할 라이브러리 기본값은 기본 라이브러리("외울 단어")

### 라이브러리 (스포티파이 플레이리스트처럼)
- 한 단어가 여러 라이브러리에 들어갈 수 있고, 카드마다 **숙련도 진행 막대**(외움 · 학습 중 · 새 단어)
- **＋ 담기**: 단어 옆 ＋를 누르면 기본 라이브러리에 바로 담고 ✓로 바뀝니다. ✓나 토스트의 "변경"을 누르면 담기 시트가 열립니다(체크 즉시 저장, 최근 쓴 라이브러리가 위).
- **빠른 삭제**: 확인 없이 바로 지우고 6초 동안 "되돌리기"(통계·라이브러리 소속까지 복구). 왼쪽으로 밀면 삭제/빼기 버튼이 나옵니다. 라이브러리 안에서는 "빼기", 완전 삭제는 '모든 단어'에서만 됩니다.
- **⋯ 메뉴**: 수정, 라이브러리에 담기, 외움 표시, 빼기/삭제
- **편집 모드**: "선택" → 여러 단어를 골라 담기·빼기·삭제 (전체 선택, 해제, 외운 단어만 선택)
- **숙련도**: 출제 0회 = 새 단어, 최근 3번 모두 정답 = 외움(직접 표시도 가능), 나머지 = 학습 중. 목록에서 숙련도로 거르기
- **자동 목록**: 오늘 복습, 최근 틀린 단어, 정답률 60% 미만, 아직 안 푼 단어, 이번 주 추가, 외운 단어 (항상 지금 기록으로 계산)
- **시험 기록**: 상세 화면에 "마지막 시험: 10/21 · 17/20"과 점수 추이 그래프, 기록마다 "그때 틀린 것만 다시 풀기"
- **▶ 암기**: 카드 앞면(영단어 + 발음) → 탭하면 뒷면(뜻·메모), "알아요 / 몰라요"로 나누고 "몰라요만 시험 보기"
- **추천 단어**: 같은 단어팩에서 아직 없는 단어, **내 수준(과 한 단계 위)의 단어**, 최근 틀린 단어, 어근이 비슷한 사전 단어 최대 10개 (＋ 추가, ✕ 다시 추천 안 함, 새로 고침)
- **난이도별 단어 (초등 1 · 2 · 3 / 중등 1 · 2 · 3 / 고등 1 · 2 · 3)**: 라이브러리 홈에 9단계 카드가 있고, 카드마다 단어 수와 내 단어·외운 단어 막대가 보입니다.
  누르면 미리 보기 → **골라 담기**(카드 50장을 넘기며 모르는 단어만), **50개 담기**(아직 안 담은 단어 50개를 무작위로), **통째로 추가**. 담은 단어는 "고등 1"처럼 그 단계 이름의 라이브러리에 모입니다.
- **내 수준**: 처음 쓸 때 수준을 고르도록 안내하고(설정에서 언제든 변경), 고른 수준은 카드에 "내 수준"으로 표시되고 추천 단어에 반영됩니다.
- **수준 진단**: 단계마다 3문제씩 영→한 객관식 27문제(모르면 "모르겠어요"). 찍어서 맞힌 몫을 빼고 계산해 추천 수준을 알려 주고, 누르면 내 수준으로 설정합니다. 진단은 시험 기록·통계에 남지 않습니다.
- **목록**: 단어마다 난이도 배지(초1 ~ 고3), 난이도로 거르기(초등·중등·고등 전체 또는 단계별, 사전에 없는 단어), 난이도순 정렬. 단어가 많으면 200개씩 보여 주고 "더 보기"
- **수능·모의고사 빈출 단어팩 6종 (611단어)**: 미리 보고 통째로 추가하거나 **골라 담기**(카드를 한 장씩 보며 "알아요/모르겠어요" → 모르는 단어로 새 라이브러리)
  - 수능·학력평가 지문에 자주 나오는 어휘를 모은 목록이며, 특정 회차 시험지에서 직접 추출한 것은 아닙니다.

### 테스트
- 맨 위 **오늘 카드**: 오늘 복습할 단어, 연속 학습일, 하루 목표(설정에서 변경)
- **복습 간격**: 맞히면 다음 복습이 1 → 3 → 7 → 14 → 30일 뒤, 틀리면 1일 뒤
- **출제 범위 목록**: 라이브러리마다 단어 수 / 복습 필요 개수 / 마지막 점수 + ▶(바로 시작). 여러 개를 골라 합쳐 출제(겹치는 단어는 한 번만), 라이브러리마다 마지막 시험 설정 기억
- 출제 개수 10 / 20 / 30 / 전체, 영→한 / 한→영 / 섞기, 주관식 / 객관식 / **추천 조합**(영→한 객관식, 한→영 주관식), 완전 무작위 / 오답률 우선
- 객관식 오답 보기는 **철자가 비슷한 단어** 우선, 단어가 4개 미만이면 사전에서 난이도가 같은 단어를 가져옵니다.
- **품사가 맞는 선에서만 너그러운 채점** (예전 버전보다 엄격해졌어요)
  - 띄어쓰기·괄호·"~을/를"은 무시하고, **품사가 같은 꼴**은 정답: 포기하다 = 포기한다 = 포기하는, 행복한 = 행복하다, 아름다운 = 아름답다, 긴 = 길다, 하얀 = 하얗다, 경제적인 = 경제적, 사람들 = 사람
  - **품사가 바뀌는 꼴은 오답**: "포기하다"에 "포기"·"포기함", "중요한"에 "중요", "결정하다"에 "결정" → "품사가 달라요 — 동사 '포기하다'(으)로 답해야 해요" 안내 (예전에는 정답이었음. 필요하면 "정답 인정"으로 직접 인정)
  - 내 뜻에는 없지만 **사전에 있는 다른 뜻**이면 정답 + 안내 (bear에 "참다")
  - 영→한 주관식에는 "품사: 동사 · 명사"처럼 답할 품사를 알려 주고, 한→영 문제는 뜻을 품사별로 묶어 보여 줍니다(명 곰 · 동 견디다).
  - 한→영: 같은 단어의 변화형(ran, studies, happier)은 정답 + "run의 변화형이에요", 어근이 같은 다른 품사(decision ↔ decide)는 오답 + "품사가 달라요", 뜻이 비슷한 다른 단어는 안내, 철자 1글자 차이는 "1글자 틀림"
  - 한 글자 차이는 "거의 정답"으로 표시하고 정답 인정 버튼을 강조합니다.
- **모르겠어요** 버튼: 답을 보지 않고 넘어가기 (오답으로 기록)
- **자동 발음**(설정): 영→한 문제·암기 카드가 나올 때, 한→영은 채점 뒤 발음을 들려줍니다.
- **이어서 풀기**: 풀던 시험을 문제마다 저장해 앱을 다시 열어도 "이어서 풀기 (7/20)"
- **결과**: 점수, 틀린 단어(내 답 vs 정답, 🔊, 메모), 틀린 것만 다시 풀기, **전체 다시 풀기**, '오답 노트'에 담기, 맞힌 단어 외움 표시

### 통계
- 최근 14일 푼 문제 수와 정답률 그래프, 많이 틀린 단어 TOP 10(▶ 바로 시험), 숙련도 비율, **난이도별 내 단어 수** (외부 라이브러리 없이 SVG)

### 설정 · 데이터
- 기본 라이브러리, **내 수준**(+ 수준 진단), **자동 발음**, 하루 목표, JSON 백업(단어·라이브러리·시험 기록·학습량 포함, 예전 버전 백업도 가져오기 가능), 7일 백업 알림
- **휴대폰**: 아래 탭 바, 아래에서 올라오는 메뉴, 글자를 입력하는 동안 탭 바 숨김, 손가락으로 밀어 삭제.
  아이폰은 "홈 화면에 추가" 안내, 안드로이드는 "앱 설치" 버튼, 홈 화면 아이콘 바로가기
- **업데이트**: 새 버전이 나오면 "새 버전이 있어요 · 지금 적용" 배너. 설정의 "앱 새로고침(캐시 갱신)"으로 직접 새로 받을 수도 있습니다.
- 예시 단어 30개 넣기·지우기, 통계 초기화, 모든 단어 삭제
- 지금 보고 있는 탭을 한 번 더 누르면 맨 위로 (라이브러리 탭은 맨 위에서 한 번 더 누르면 라이브러리 홈으로)

### 사전과 난이도에 대해
- 뜻은 이 앱을 위해 새로 정리한 것으로, 많이 쓰는 뜻부터 품사별로 1~4개씩 적었습니다. 사전에 없는 단어는 등록 화면에서 온라인 참고(영영 뜻·참고용 번역·네이버 사전)를 보여 줍니다.
- 난이도는 초등 1~3은 직접 고른 기초 단어이고, 중등 1 ~ 고등 3은 교육과정 수준 판단과 영어 사용 빈도(wordfreq)를 섞어 나눴습니다. 교육부 기본 어휘 목록이나 특정 교재를 그대로 옮긴 것은 아니라서 학교·교재에 따라 조금 다를 수 있어요.

css/style.css       스타일 (가로·세로 화면, 다크 모드)
js/storage.js       localStorage 저장/불러오기, 데이터 형식 맞추기(normalize)
js/ui.js            토스트(되돌리기 버튼), 대화상자, 액션 시트 등 공용 UI
js/speech.js        발음 듣기 (Web Speech API)
js/samples.js       예시 단어 30개
js/packs.js         수능·모의고사 빈출 단어팩 데이터
js/dict-data.js     영한 사전 데이터 { 영단어: [난이도, "품사:뜻,뜻;품사:뜻"] } (자동 생성)
js/dict.js          사전 찾기, 자동완성, 변화형 → 원형, 한글로 찾기, 온라인 참고
js/korean.js        한국어 뜻 비교 (품사가 같은 꼴만 정답, 품사가 다르면 안내)
js/levels.js        난이도(초등 1 ~ 고등 3), 난이도별 단어, 내 수준, 수준 진단
js/words.js         단어 데이터 조작, 되돌리기, 일괄 등록
js/review.js        숙련도, 복습 간격, 연속 학습일, 자동 목록
js/history.js       시험 기록, 점수 추이 그래프
js/recommend.js     추천 단어
js/libraries.js     라이브러리 (만들기, 편집, 담기 시트, 단어팩 추가)
js/list.js          라이브러리 안 단어 목록, 밀어서 삭제, ⋯ 메뉴, 편집 모드
js/register.js      단어 하나 등록 (자동완성, 뜻 칩, 방금 등록한 단어)
js/quiz.js          테스트 출제 / 채점 / 이어서 풀기 / 결과
js/cards.js         암기 카드, 단어팩 골라 담기
js/stats.js         통계 탭, 테스트 탭의 오늘 카드
js/backup.js        JSON 백업 / 7일 백업 알림
js/app.js           앱 시작, 탭 전환, 설정 화면, 업데이트
icons/              앱 아이콘
```

### localStorage 키

| 키 | 내용 |
| --- | --- |
| `wt.words` | 단어 (뜻, 메모, 출제·오답 횟수, 최근 결과, 복습 간격 등) |
| `wt.libraries` | 라이브러리 (단어 ID 목록, 표지 색, 숨긴 추천) |
| `wt.settings` | 설정 (시험 설정, 출제 범위, 라이브러리별 설정, 기본 라이브러리, 하루 목표, 내 수준, 자동 발음) |
| `wt.history` | 시험 기록 (최대 300개) |
| `wt.daily` | 날짜별 푼 문제 수·정답 수 (연속 학습일, 통계) |
| `wt.quizRun` | 진행 중인 시험 (이어서 풀기) |
| `wt.recentAdds` | 방금 등록한 단어 (되돌리기) |
| `wt.meta` | 마지막 백업 시각 등 |

예전 버전 데이터에 없는 값은 `storage.js`의 normalize 함수가 기본값으로 채우므로, 업데이트해도 기존 단어·라이브러리·설정이 그대로 남습니다.

## GitHub Pages에 올리기

1. **파일을 `main` 브랜치에 올립니다.**
   이 저장소(`word-test`)의 `main` 브랜치 맨 위에 `index.html`이 있어야 합니다.
2. GitHub에서 저장소 페이지를 열고 **Settings**(설정) 탭을 누릅니다.
3. 왼쪽 메뉴에서 **Pages**를 누릅니다.
4. **Build and deployment** 아래 **Source**를 **Deploy from a branch**로 고릅니다.
5. **Branch**는 `main`, 폴더는 `/ (root)`로 고르고 **Save**를 누릅니다.
6. 1~2분 기다린 뒤 Pages 화면을 새로 고치면 맨 위에
   `Your site is live at https://<아이디>.github.io/word-test/` 주소가 나타납니다.
   (저장소 **Actions** 탭에서 배포 진행 상황을 볼 수 있습니다.)
   - 무료 계정이면 GitHub Pages를 쓰려면 저장소가 **Public**(공개)이어야 합니다. 단어 데이터는 기기에만 저장되므로 저장소에 올라가지 않습니다.

### 아이패드 홈 화면에 추가하기

1. 아이패드 **Safari**로 위 주소를 엽니다. (홈 화면 추가는 Safari에서 하는 것이 가장 확실합니다.)
2. 주소창 옆 **공유 버튼(□↑)**을 누릅니다.
3. **홈 화면에 추가**를 누르고 → **추가**를 누릅니다.
4. 홈 화면의 "단어장" 아이콘으로 실행하면 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 없어도 동작합니다.

### 휴대폰에서 앱으로 쓰기

휴대폰에서는 화면 아래에 탭 바(단어 등록 · 라이브러리 · 테스트 · 통계 · 설정)가 나오고, 메뉴는 아래에서 올라오는 시트로 열려 앱처럼 쓸 수 있어요.

- **아이폰**: **Safari**로 주소를 열고 → 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**
  (처음 열면 화면 위에 이 방법을 알려 주는 안내가 떠요.)
- **안드로이드**: **Chrome**으로 주소를 열면 화면 위에 **앱 설치** 버튼이 떠요. 안 보이면 오른쪽 위 **⋮ 메뉴 → 앱 설치**(또는 **홈 화면에 추가**).
  설치한 아이콘을 길게 누르면 **단어 등록 · 테스트 · 라이브러리** 바로가기가 나와요.
- 설치 상태는 **설정 → 앱**에서 볼 수 있어요.
- 휴대폰과 아이패드의 데이터는 **따로** 저장돼요. 옮기려면 한쪽에서 **JSON 내보내기** → 다른 쪽에서 **JSON 가져오기(합치기)** 하세요.

### 수정한 뒤 다시 배포하기

1. 파일을 고쳐서 `main`에 올립니다.
2. **`sw.js`의 `CACHE_VERSION`을 올려 주세요** (예: `'v1'` → `'v2'`).
   이 값을 바꾸지 않으면 아이패드가 예전에 캐시해 둔 파일을 계속 씁니다.
3. 앱을 열면 새 버전을 받아 두고 "새 버전이 있어요 · 지금 적용" 배너가 뜹니다. 누르면 바로 적용됩니다.
   (배너가 안 보이면 설정 → "앱 새로고침(캐시 갱신)")

## 주의 사항 (데이터)

- 데이터는 **그 기기, 그 브라우저 안에만** 저장됩니다. 홈 화면 앱과 Safari 탭은 저장 공간이 서로 따로입니다. 처음부터 홈 화면 앱으로 쓰세요.
- 홈 화면 앱을 삭제하면 데이터도 함께 지워집니다. **설정 → JSON 내보내기**로 주기적으로 백업하세요. 아이패드에서는 공유 시트가 열리며 **"파일에 저장"**으로 iCloud Drive 등에 저장할 수 있습니다.
- 다른 기기로 옮길 때는 백업 파일을 **설정 → JSON 가져오기**로 불러오세요. 시험 기록과 학습량도 함께 옮겨집니다.
- 사전에 없는 단어의 온라인 참고(영영 뜻·참고용 번역)는 인터넷이 될 때만 나옵니다. 참고용 번역은 기계 번역이라 틀릴 수 있어요.

python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
